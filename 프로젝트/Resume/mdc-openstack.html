STEP 3VM 접속 후 초기 실행

GPU VM에 SSH 접속한 뒤 네트워크 확인 → 필수 패키지 → NVIDIA 드라이버 설치 순서로 진행합니다.

  1. DNS 설정 및 외부 저장소 연결 확인

    네임서버를 지정하고 Ubuntu 저장소에 접속되는지 확인합니다.

    echo "nameserver 8.8.8.8" | sudo tee /etc/resolv.conf
getent hosts archive.ubuntu.com
ping -c 3 archive.ubuntu.com
sudo apt update

  2. GPU 장치 인식 확인

    VM에 GPU가 패스스루(PCI)로 붙어 있는지 확인합니다.

    lspci -nn | grep -Ei 'NVIDIA|AMD|3D controller'

  3. 패키지 업데이트 및 필수 도구 설치

    드라이버 빌드에 필요한 커널 헤더 · 빌드 도구를 설치합니다.

    sudo apt update
sudo apt install -y pciutils ubuntu-drivers-common build-essential dkms linux-headers-$(uname -r)

  4. NVIDIA GPU 드라이버 설치

    오픈 커널 모듈 드라이버를 설치한 뒤 VM을 재부팅합니다.

    sudo apt install -y nvidia-driver-595-open
sudo reboot

  5. 재부팅 후 GPU 동작 확인

    드라이버 로드 상태와 GPU 목록을 확인합니다.

    nvidia-smi
nvidia-smi -L
